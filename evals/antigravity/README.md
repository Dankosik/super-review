# Antigravity adapter evidence

The baseline has no Antigravity adapter. This addition supplies native discovery,
custom-role dispatch and collection while preserving each skill's criterion,
source policy and report format. It changes no coverage or judgment default.

Contrasts in `inputs.json` isolate help/review, named/generic activation,
available/missing custom agents, inherited/unsupported model selection,
missing/full results, fresh challenges versus retained reader contexts, and
available/unavailable revision contents. `cases.json` is evaluator-only grading
material. Give a stage run only its selected input and the installed entrypoint,
adapter and applicable core contract/workflow; never send the graders to readers.
See the parent evaluation protocol for identical-condition comparisons.

Native model runs and baseline/candidate behavioral comparisons: **NOT RUN**.
There are no raw model outputs, task IDs or observed model/effort values to
report. CLI 1.5.9 strict plugin validation found four skills, six agents and no
findings; this is a configuration probe, not model inference or end-to-end
execution. Package tests check extraction, resource relocation, exact bytes and
checksums. They establish no improvement in routing or recommendation quality.

A later native comparison should retain all raw traces, failures, actual model
identity/effort when exposed, tool calls and reports. In particular inspect
discovery, tool allowlist enforcement and separate challenger invocations.
