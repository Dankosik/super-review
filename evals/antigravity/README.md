# Antigravity adapter evidence

The initial baseline had no Antigravity adapter. That addition supplied native discovery,
custom-role dispatch and collection while preserving each skill's criterion,
source policy and report format. It changes no coverage or judgment default.

Contrasts in `inputs.json` isolate help/review, named/generic activation,
available/missing custom agents, inherited/unsupported model selection,
missing/full results, fresh challenges versus retained reader contexts, and
available/unavailable revision contents. `cases.json` is evaluator-only grading
material. Give a stage run only its selected input and the installed entrypoint,
adapter and applicable core contract/workflow; never send the graders to readers.
See the parent evaluation protocol for identical-condition comparisons.
